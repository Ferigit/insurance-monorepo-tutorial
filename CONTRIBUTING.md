# Contributing

Create a focused branch, describe the user-visible change, and keep feature code and tests together. Run `pnpm format`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`. Review RTL, keyboard access, and mobile layout for UI changes. Never commit secrets or real customer data. The Husky pre-commit hook runs formatting checks, lint, type checking, and tests when Git hooks are enabled. CI repeats these checks and builds the app.
